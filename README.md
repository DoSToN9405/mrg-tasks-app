# ⚡ MRG Tasks / MRG Miner — Telegram Mini App (Full Replica)

Точная, полностью автономная копия популярного Telegram Mini App **MRG Tasks** (`app.mrgtoken.xyz`), созданная на основе глубокого реверс-инжиниринга оригинального бандла.

---

## 🔍 Анализ ошибки `net::ERR_INTERNET_DISCONNECTED`

При переходе по ссылке:
```text
https://app.mrgtoken.xyz/#tgWebAppData=user%3D%7B"id"%3A1873407633,"first_name"%3A"Mr.DoSToN","last_name"%3A"| Tasky 🐻","username"%3A"DoSToN_SoDiQoV","language_code"%3A"ru",...%7D&tgWebAppVersion=9.6&tgWebAppPlatform=android&...
```
браузер внутри Telegram выдал ошибку `net::ERR_INTERNET_DISCONNECTED` по следующим причинам:

1. **Проблема на стороне сети пользователя или DNS-провайдера**:
   - Домен `app.mrgtoken.xyz` находится за Cloudflare, а бэкенд проекта расположен на `mrg.up.railway.app`.
   - Если в момент клика на устройстве кратковременно пропал интернет, либо провайдер/Telegram WebView заблокировал обращение к зоне `.xyz` или сервису Cloudflare Turnstile (`challenges.cloudflare.com`), браузер мгновенно возвращает системную ошибку `ERR_INTERNET_DISCONNECTED`.
2. **Зависимость оригинального приложения от сторонних CDN**:
   - Оригинальное веб-приложение блокирует запуск при отсутствии соединения с внешним API и Adsgram SDK (`sad.adsgram.ai`).

### Решение в созданной копии:
- **Offline-First Architecture**: приложение полностью сохраняет состояние (балансы, таймеры майнинга, уровень, выполненные задания, реферальный сквад, историю транзакций) в `localStorage`.
- Приложение **никогда не зависает с белым экраном или ошибкой сети** — оно моментально открывается и работает даже при полном отсутствии интернета!

## 🧮 Математическая модель майнинга и уровней (Извлечено из исходного кода)

### 1. Скорость хешрейта (TH/s) — функция `le(level)`:
- **Уровень 1**: `0.20 TH/s`
- **Уровень 203**: `7.56 TH/s`
- **Уровень 1000**: `5,000.00 TH/s`
- **Формула от 1 до 203**:
  $$\text{Speed} = 0.2 + (\text{level} - 1) \times 0.03643564$$
- **Формула от 204 до 1000**:
  $$\text{Speed} = 7.56 + (5000 - 7.56) \times \left(\frac{\text{level} - 203}{797}\right)^{2.1}$$

### 2. Суточная добыча MRG — функция `He(level)`:
$$\text{Daily Output} = \text{round}(\text{Speed} \times 25)$$
- На 1 уровне: `5 MRG/день`
- На 203 уровне: `189 MRG/день`
- На 1000 уровне: `125,000 MRG/день`

### 3. Требуемый баланс токенов (Proof-of-Holding) — функция `gt(level)`:
Уровни открываются автоматически, если пользователь держит необходимое количество MRG на кошельке:
- Уровень 1: `100 MRG`
- Уровень 203: `10,000 MRG`
- Уровень 1000: `3,875,968,992 MRG`

## 📱 Реализованные экраны и компоненты

### 1. ⛏️ Вкладка «Майнинг» (`MinePage`)
- **Интерактивный 3D-реактор монеты** (диск 184x184 px с градиентным кольцом 228 px):
  - Эффект `coin-shine` (скользящий световой блик).
  - 3D-наклон диска при касании в зависимости от координат курсора/пальца.
  - Анимированные вылетающие частицы монет при тапе.
- **Живой счетчик награды в реальном времени**: обновляется каждые 100 мс с точностью до 6 знаков после запятой (`0.000000 MRG`).
- Индикатор обратного отсчета суточного окна (`hh:mm:ss`) с пульсирующим статусом.
- Кнопка **«ЗАБРАТЬ НАГРАДУ»** со всплывающим уведомлением.
- Карточки характеристик майнера и баланса (в приложении и на кошельке).
- Встроенный интерактивный график **DexScreener** (пара MRG/GRAM).

### 2. 🏪 Вкладка «Майнеры» (`MinersPage`)
- Прогрессионный магазин от 1 до 1000 уровней.
- Карточки с бейджами уровней (`Lv X`), статусами (`ТЕКУЩИЙ`, `РАЗБЛОКИРОВАН`, `НУЖНО X MRG`).
- Всплывающее модальное окно деталей уровня с прогресс-баром активов и кнопками разблокировки.
- Модальное окно достижения при переходе на новый уровень с кнопкой «Поделиться в Telegram».

### 3. 📋 Вкладка «Задания» (`TasksPage`)
- **Ежедневный 7-дневный стрик**:
  - День 1 (+5), День 2 (+6), День 3 (+7), День 4 (+8), День 5 (+9), День 6 (+10), День 7 (+15 MRG).
- Список социальных и партнерских заданий:
  - 15-секундный таймер проверки с обратным отсчетом (`ЖДИТЕ 15С`).
  - Переход кнопки в статус `ЗАБРАТЬ` по окончании таймера.

### 4. 👥 Вкладка «Друзья / Сквад» (`FriendsPage`)
- 10% пул комиссий в реальном времени от добычи приглашенных друзей.
- Кнопка «Забрать комиссию сквада».
- Бонус +100 MRG за каждого приглашенного.
- Генератор реферальной ссылки и кнопка шаринга в Telegram.
- Список участников команды со скоростью майнинга, заработком и кнопкой «Пнуть» (`Nudge`).
- Мультиязычность (Русский, Английский, Индонезийский, Испанский, Турецкий, Арабский, Фарси).

### 5. 💳 Вкладка «Кошелек и активы» (`WalletPage`)
- Общий баланс MRG (In-App + Tonkeeper).
- **Вывод средств (`Withdraw`)**:
  - Автоматическая привязка к подключенному кошельку.
  - Расчет сетевой комиссии с учетом скидки Genesis NFT.
- **Гайд покупки на DEX**: официальный контракт токена `EQDj-zlSvj4Au154XjsU7ATzt13p8JjYEs0weVv1rVbCJSn0`.
- **Верификация аккаунта (KYC)**: видео-инструкция для `@MRG_Verification_bot`.
- **Margcoin Genesis NFT**: скидки на комиссию 10%, 20%, 35%, 50% и освобождение от KYC.
- История последних транзакций.

## 🛠️ Запуск проекта

### 1. Запуск фронтенда
```bash
npm run dev
```
Откройте `http://localhost:5173`.

### 2. Сборка для продакшена
```bash
npm run build
```

### 3. Запуск Telegram-бота
```bash
cp .env.example .env
# Заполните токен бота
npm run bot
```
